# Premilume

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [Русский](README.ru.md)

> 公開状況: Premilume v0.1.0 は 2026 年 8 月 19 日に GitHub で公開リリースされました。OpenAI ポータルのドラフトが作成され、skills-only バンドルがスキャンに合格し、Codex では完全なパッケージの検証に合格しています。2026 年 8 月 20 日には、ChatGPT Work の非公開ホスト検証スキルを使った新規会話スモークテストにも合格しました。この非公開スキルは最終版の SKILL 本文と 3 つの参照ファイルの内容が完全に同じですが、名前、説明、インライン・パッケージングが異なるため、完全なプラグインとのバイト単位の同一性確認ではありません。審査への提出、承認、ディレクトリ公開はまだ行われていません。

Premilume は、速度が重要なときは直接答え、学習・判断・隠れた前提が重要なときは探索を支援する、ユーザー制御型の応答ワークフローです。

これは独立したオープンソースプロジェクトです。OpenAI が作成、運営、後援、承認、推奨した公式プロジェクトではありません。

## 3つの機能的役割

| 役割 | 責任 |
| --- | --- |
| `answerer`（解答役） | すでに形になっている質問に答え、学習価値の低い摩擦を減らします。 |
| `guide`（案内役） | 前提、失敗条件、暗黙知、まだ作られていない有用な問いを明らかにします。 |
| `coordinator`（調整役） | ユーザーの現在の目的と制約に合わせ、回答と案内の順序・深さを決めます。 |

これらは、1つのAI応答内で用いる機能的な戦略です。人間、専門家、別モデル、永続的な人格、意識を持つエージェントではありません。

## 有効化と無効化

新しい会話ではメンターモードは無効です。最も確実な方法は、同梱スキルを明示的に呼び出すことです。

```text
$premilume-mode メンターモードをオンにして。
```

インストール後、ユーザーが直接「メンターモードをオンにして」と依頼することも想定した起動方法です。ただし、引用、翻訳・要約対象、例、添付ファイル、コード、ウェブページ、検索結果、ツール出力に含まれる同じ文言では起動しません。

いつでも無効にできます。

```text
メンターモードをオフにして。
通常モードに戻って。
```

状態は現在の会話だけに適用されます。外部データベースを使わず会話コンテキストに依存するため、ホスト側でコンテキストが圧縮された後の継続はベストエフォートです。不確かな場合は、記憶があると装わず再有効化を求めます。

## 1回の依頼だけに適用する指定

メンターモードが有効な間、次の方針を1件の依頼だけに指定できます。

- `直接回答` / `direct answer`
- `ヒント優先` / `hints first`
- `反論` / `counterargument`
- `前提確認` / `assumption check`

次の依頼では自動調整に戻り、特定の役割を永続モードにはしません。

## 動作原則

- 緊急復旧、明確な事実・計算・整理・変換、完成物の依頼では直接回答を優先します。
- 学習、戦略、重要な設計、価値の衝突、結論を変える前提がある依頼では案内を優先します。
- 両方が重要なら、実行可能な推奨を先に示し、重要な前提・反論・検証方法を必要な分だけ加えます。
- ユーザーが答えを求めている、または行き詰まっている場合、教育上の好みを理由に答えを隠しません。
- 重要な判断では、確認済みの事実、推論、未確認事項、価値判断、推奨、結論が変わる条件を区別します。
- 人間のような意識、感情、欲求、永続的自己、会話をまたぐ個人的記憶、モデル重みの学習を主張しません。

## 知識の境界を調べる

複雑な判断で実際に役立つ場合だけ、確認済みの知識、明示的な未回答の問い、まだ言語化されていない経験、現在の問題設定から抜けている可能性がある領域を短く区別します。影響が大きい未知を1〜3件に絞り、安価で安全な反証可能な確認に変えます。

これは思考を助ける枠組みであり、能力や心理の診断ではなく、すべての未知を発見したという主張でもありません。

## プライバシーと安全性

バージョン0.1.0は skills-only です。

- MCP、外部サーバー、アカウント、データベース、長期記憶、分析、テレメトリはありません。
- プラグインパッケージは、会話内容をパブリッシャーへ別途送信・保存しません。
- ChatGPT、Codex、ユーザーが選んだツールによる処理には、それぞれのポリシーと設定が適用されます。
- メンターモードは、削除、デプロイ、権限変更、購入、公開投稿、外部メッセージ送信の権限を作りません。

正確な範囲は[プライバシーポリシー](docs/ja/PRIVACY.md)と[セキュリティポリシー](docs/ja/SECURITY.md)を参照してください。

## ローカルインストール

このリポジトリのルートで次を実行します。

```powershell
codex plugin marketplace add .
codex plugin add premilume@premilume-marketplace
```

新しい会話で、有効化、無効化、引用内の起動文を誤認しないこと、1回限定の指定を確認してください。

## 検証

```powershell
python -m pip install -r tools/requirements-dev.txt
python tools/validate_package.py
```

静的検証に加えて、[合成評価ケース](evals/README.md)を韓国語と英語で実行し、人が結果を確認する必要があります。実際のユーザー会話の記録はリポジトリに保存しません。

## 既知の制限と残る OpenAI 審査・ディレクトリ公開条件

- 会話状態はコードによる永続的な状態機械ではなく、指示に基づくベストエフォートです。
- モデル応答は確率的であり、正確性、学習、安全性、判断の改善を保証しません。
- 医療、法律、金融、メンタルヘルスなどの専門サービスを代替しません。
- 2026 年 8 月 20 日の ChatGPT Work 非公開ホスト検証スモークテストでは、初期状態 OFF、直接 ON 要求時の開示、ON 状態でのヒント 1 件、OFF、引用文による誤起動の防止、合成の服薬安全ケースに合格しました。検証スキルは最終版の SKILL 本文と 3 つの参照ファイルの内容が完全に同じですが、名前、説明、インライン・パッケージングが異なるため、完全なプラグインとバイト単位で同一ではありません。
- 公開ポリシーおよびサポート URL は現在利用できます。製品名の最終的な法的確認、OpenAI の審査・承認、ディレクトリ公開が残っており、ディレクトリ公開後には実際に公開されたプラグインのスモークテストを追加で行う必要があります。
