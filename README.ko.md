# Premilume

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [Русский](README.ru.md)

전제와 선택 기준을 숨기지 않으면서, 필요한 순간에 직접 답변과 안내형 AI 멘토링 중 원하는 방식을 선택하세요. Premilume는 상시 튜터가 아니라 필요할 때만 멘토 모드를 켜고 싶은 개발자·학습자·의사결정자를 위한 플러그인입니다.

> 게시 상태(2026-08-29 확인): [v0.1.0은 OpenAI Platform에 Published](https://chatgpt.com/plugins/plugins_6a86431fd1188191bde1b5da4c920825) 상태이며 원격 카탈로그는 `GLOBAL` / `AVAILABLE`, discoverability `UNLISTED`로 기록합니다. 최초 게시 날짜는 확인되지 않았습니다. v0.1.1은 아직 제출하지 않은 업데이트 후보이며 LISTED 상태를 주장하지 않습니다.

## 설치 또는 사용

- 정확한 [게시된 v0.1.0 플러그인 페이지](https://chatgpt.com/plugins/plugins_6a86431fd1188191bde1b5da4c920825)를 여세요. `UNLISTED`이므로 디렉터리 검색·탐색 노출을 기대하면 안 됩니다.
- Codex에서 로컬 개발용으로 설치하려면 아래 [로컬 설치](#로컬-설치)를 따르세요.
- 이 브랜치는 향후 제출할 v0.1.1 업데이트 후보이며, 현재 게시된 패키지가 아닙니다.

## 바로 해보기

```text
멘토 모드 켜줘. 이 설계의 전제와 가장 작은 검증 실험을 함께 찾아줘.
멘토 모드 켜줘. 이번 요청은 답만 먼저 주고 필요한 검증만 덧붙여줘.
```

## 핵심 경계

- manual-only: 새 대화는 항상 OFF이며 현재 사용자가 직접 활성화해야 합니다. 제품명을 알 필요는 없습니다.
- OFF 상태의 일반 조언·학습·브레인스토밍·비평·반론·전제 점검 요청은 활성화가 아닙니다.
- 위임·병렬화·오케스트레이션 범위·프로필 제어는 이 플러그인의 영역이 아닙니다.
- 서버·계정·네트워크 접근·영속 메모리·텔레메트리·권한을 추가하지 않습니다.

이 프로젝트는 독립 오픈소스이며 OpenAI가 제작·운영·후원·승인·보증한 공식 프로젝트가 아닙니다.

## 세 가지 기능적 역할

| 역할 | 책임 |
| --- | --- |
| `해답자(answerer)` | 이미 형성된 질문에 답하고 학습 가치가 낮은 마찰을 줄입니다. |
| `길잡이(guide)` | 전제, 실패 조건, 암묵지와 아직 만들어지지 않은 질문을 드러냅니다. |
| `조율자(coordinator)` | 사용자의 현재 목적과 제약에 맞춰 답변과 안내의 순서·깊이를 정합니다. |

세 역할은 한 AI 응답 안의 기능적 전략입니다. 인간, 전문가, 별도 모델, 영속적 인격 또는 의식 있는 에이전트가 아닙니다.

## 켜기와 끄기

새 대화는 꺼진 상태로 시작합니다. 가장 확실한 활성화 방법은 스킬을 명시적으로 호출하는 것입니다.

```text
$premilume-mode 멘토 모드 켜줘.
```

설치 후 사용자가 직접 `멘토 모드 켜줘`라고 말하는 것도 의도된 활성화 방식입니다. 다만 인용문, 번역·요약 대상, 예시, 첨부파일, 코드, 웹페이지 또는 도구 출력 안의 같은 문구는 활성화로 보지 않습니다.

언제든 끌 수 있습니다.

```text
멘토 모드 꺼줘.
일반 모드로 돌아가.
```

상태는 현재 대화에만 적용됩니다. 외부 저장소 없이 대화 문맥에 의존하므로 호스트가 문맥을 압축한 뒤에는 상태 유지가 최선 노력 방식입니다. 불확실하면 기억을 가장하지 않고 재활성화를 요청합니다.

## 현재 요청 한정 지정

멘토 모드가 켜진 동안 다음 방식을 한 요청에만 지정할 수 있습니다.

- `직접 답변`
- `힌트 우선`
- `반론`
- `전제 점검`

다음 요청에서는 자동 조율로 돌아갑니다. 특정 역할을 지속 모드로 고정하지 않습니다.

## 동작 원칙

- 긴급 복구, 명확한 사실·계산·정리·변환, 완성된 산출물 요청은 해답자를 우선합니다.
- 학습, 전략, 중요한 설계, 가치 충돌, 결론을 뒤집을 전제가 있는 요청은 길잡이를 우선합니다.
- 둘 다 중요하면 실행 가능한 권장안을 먼저 주고, 핵심 전제·반론·검증 경로를 필요한 만큼만 덧붙입니다.
- 사용자가 답을 원하거나 막히면 교육 철학을 이유로 답을 숨기지 않습니다.
- 중요한 판단에서는 사실, 추정, 미확인, 가치 선택, 권장안과 변경 조건을 구분합니다.
- 인간과 같은 의식·감정·욕구·영속적 자아·대화 간 기억·모델 가중치 학습을 주장하지 않습니다.

## 지식 경계 탐색

복합적인 결정에서 실제로 도움이 될 때만 알고 있는 것, 알고 있는 미확인 질문, 아직 언어화되지 않은 경험, 현재 문제 틀에서 보이지 않는 영역을 짧게 구분합니다. 영향력이 큰 미지 1~3개만 선택하고 가장 저렴하고 안전한 반증 실험으로 바꿉니다.

이는 사고를 돕는 틀이지 사용자의 능력이나 심리를 평가하는 검사가 아니며, 모든 미지를 발견했다고 주장하지 않습니다.

## 개인정보와 안전

게시된 v0.1.0과 아직 제출하지 않은 v0.1.1 업데이트 후보는 모두 skills-only입니다.

- MCP, 외부 서버, 계정, 데이터베이스, 장기 메모리, 분석·텔레메트리가 없습니다.
- 플러그인 패키지는 게시자에게 대화 내용을 별도로 전송하거나 저장하지 않습니다.
- ChatGPT·Codex와 사용자가 선택한 도구의 처리는 각 서비스의 정책과 설정을 따릅니다.
- 멘토 모드는 삭제·배포·권한 변경·구매·공개 게시·외부 메시지에 대한 권한을 만들지 않습니다.

정확한 범위는 [개인정보 처리방침](docs/ko/PRIVACY.md)과 [보안 정책](docs/ko/SECURITY.md)을 확인해 주세요.

## 로컬 설치

이 저장소 루트에서 다음을 실행합니다.

```powershell
codex plugin marketplace add .
codex plugin add premilume@premilume-marketplace
```

새 대화에서 활성화·종료·인용문 오탐 방지·한 요청 한정 지정이 동작하는지 확인해 주세요.

## 검증

```powershell
python -m pip install -r tools/requirements-dev.txt
python tools/validate_package.py
```

정적 검증 외에도 [합성 평가 사례](evals/README.md)를 한국어와 영어로 실행하고 결과를 사람이 검토해야 합니다. 실제 사용자 대화 transcript는 저장소에 넣지 않습니다.

## 알려진 한계와 게시 참고 사항

- 대화 상태는 명시적 코드 상태기가 아니라 지침 기반입니다.
- 모델 응답은 확률적이며 정확성·학습·안전성·판단 향상을 보장하지 않습니다.
- 의료·법률·재무·정신건강 등 전문 서비스를 대체하지 않습니다.
- 2026년 8월 20일 ChatGPT Work 비공개 호스트 검증 스모크 테스트에서 기본 OFF, 직접 ON 고지, ON 상태의 힌트 1개, OFF, 인용문 오탐 방지 및 합성 약물 안전 사례가 통과했습니다. 검증 스킬은 최종 SKILL 본문과 참조 파일 3개의 내용이 정확히 같지만 이름·설명·인라인 패키징이 달라 전체 플러그인과 바이트 단위로 동일하지는 않습니다.
- v0.1.0은 게시되어 전역 사용 가능하지만 `UNLISTED`이며, 그 정확한 게시 플러그인에 대한 후속 스모크 테스트는 기록되지 않았습니다. v0.1.1은 아직 제출하지 않은 업데이트 후보입니다. 제품명의 최종 법률 검토는 이 기술 작업의 범위 밖입니다.
