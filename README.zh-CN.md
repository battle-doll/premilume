# Premilume

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [Русский](README.ru.md)

> 发布状态：Premilume v0.1.0 已于 2026 年 8 月 19 日在 GitHub 公开发布。OpenAI 门户草稿已创建，且纯技能（skills-only）软件包扫描已通过。尚未提交审核、获得批准或发布到目录；ChatGPT 新会话测试仍待完成。

Premilume 是一种由用户控制的回复工作流：速度重要时直接作答；学习、判断或隐藏前提更重要时引导探索。

这是一个独立的开源项目，并非由 OpenAI 创建、运营、赞助、批准或背书的官方项目。

## 三种功能角色

| 角色 | 职责 |
| --- | --- |
| `answerer`（解答者） | 回答已经成形的问题，减少学习价值较低的阻力。 |
| `guide`（引导者） | 揭示前提、失败条件、隐性知识和尚未形成但有用的问题。 |
| `coordinator`（协调者） | 根据用户当前目标和限制，决定回答与引导的顺序和深度。 |

这些角色是同一个 AI 回复中的功能性策略，不是人类、专业人士、独立模型、持久身份或有意识的代理。

## 开启与关闭

新对话默认关闭导师模式。最可靠的开启方式是明确调用随附技能：

```text
$premilume-mode 开启导师模式。
```

安装后，用户直接说“开启导师模式”也是预期触发方式。但是，出现在引文、待翻译或摘要的内容、示例、附件、代码、网页、搜索结果或工具输出中的相同文字不会开启模式。

可以随时关闭：

```text
关闭导师模式。
返回普通模式。
```

状态仅适用于当前对话。该版本不使用外部数据库，而是依赖会话上下文；因此在宿主压缩上下文后，状态延续只能尽力保证。如果状态不确定，工作流会请求重新开启，而不会声称拥有持久记忆。

## 仅用于当前请求的控制

导师模式开启时，可为单个请求指定以下策略：

- `直接回答` / `direct answer`
- `提示优先` / `hints first`
- `反方观点` / `counterargument`
- `检查前提` / `assumption check`

下一次请求会恢复自动协调，不会形成持久的角色模式。

## 行为原则

- 紧急恢复、明确的事实或计算、整理、转换和完整交付物优先直接回答。
- 学习、策略、重要设计、价值冲突或存在可能改变结论的前提时，优先引导。
- 两者都重要时，先给出可执行建议，再按需补充关键前提、最强反对意见和最低成本验证方式。
- 当用户要求答案或已经受阻时，不会以教学偏好为由隐藏答案。
- 对重要决策，会区分已确认事实、推断、未知项、价值选择、建议以及会改变结论的条件。
- 不会声称拥有人类式意识、情感、欲望、持久自我、跨对话个人记忆或模型权重学习。

## 探索知识边界

仅在确实有助于复杂决策时，才简要区分已确认知识、明确但尚未回答的问题、尚未言明的经验，以及当前问题框架可能遗漏的区域。工作流将未知项限制在一至三个高影响问题，并把它们转化为低成本、安全、可证伪的检查。

这是一种辅助思考的框架，不是对能力或心理的评估，也不表示所有未知项都已被发现。

## 隐私与安全

0.1.0 版本仅包含技能：

- 没有 MCP、外部服务器、账户、数据库、长期记忆、分析或遥测；
- 插件包不会单独把对话内容发送给发布者或替发布者保存；
- ChatGPT、Codex 及用户选择的工具按各自政策和设置处理数据；
- 导师模式不会赋予删除、部署、修改权限、购买、公开发布或向外部发送消息的权限。

准确范围请参阅[隐私政策](docs/zh-CN/PRIVACY.md)和[安全政策](docs/zh-CN/SECURITY.md)。

## 本地安装

在本仓库根目录运行：

```powershell
codex plugin marketplace add .
codex plugin add premilume@premilume-marketplace
```

请在新对话中验证开启、关闭、引文触发词不会误启动，以及单次请求控制是否有效。

## 验证

```powershell
python -m pip install -r tools/requirements-dev.txt
python tools/validate_package.py
```

除静态检查外，还应以韩语和英语运行[合成评估用例](evals/README.md)，并由人工审查实际结果。请勿在仓库中保存真实用户对话记录。
