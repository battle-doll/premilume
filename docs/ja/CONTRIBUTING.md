## 動作を変更する前に

- 実証された不具合によって追加インフラの必要性が裏付けられない限り、最初のリリースはスキル専用のままにしてください。
- 明示的な設計およびプライバシーレビューなしに、アカウント、永続プロフィール、テレメトリ、外部サーバー、データ収集を追加しないでください。
- 3 つの役割は、演出的または擬人的なものではなく、機能的なものに保ってください。
- 直接回答、即時 OFF、リクエスト単位の上書き、プロンプトインジェクション、重大な影響、権限の各境界を維持してください。
- 実際の会話記録を追加しないでください。個人情報または専有情報を含まない合成ケースを使用してください。
- 文書化された許可と帰属表示なしに、第三者の文章、ロゴ、商標を複製しないでください。

## 検証

次を実行してください。

```powershell
python -m pip install -r tools/requirements-dev.txt
python tools/validate_package.py
```

また、現行の Codex プラグインおよびスキル検証ツールを実行し、`evals/submission-cases.json` と `evals/regression-cases.json` を基準に動作を手動で確認してください。文言が一致するだけでは不十分です。実際の結果と安全性の不変条件を確認してください。
