## 適用範囲

本ポリシーは、`battle-doll` が公開する Premilume オープンソース・スキル専用プラグインパッケージに適用されます。ユーザーが別途選択する ChatGPT、Codex、GitHub、その他のツールまたはサービスのプライバシー条件に代わるものではありません。

## プラグイン公開者が取り扱うデータ

バージョン 0.1.0 には、公開者が運営するサーバー、MCP サービス、ユーザーアカウント、データベース、分析、広告、テレメトリはありません。パッケージに含まれるのは指示と静的アセットのみです。

公開者は、プラグインパッケージを通じてユーザーのプロンプトまたは会話内容を受信、収集、送信、保持しません。したがって、当該ランタイムコンテンツについて公開者が保持する期間はゼロです。

プラグインは、パスワード、ワンタイムコード、API キー、支払認証情報、政府発行の識別子、健康記録を要求しません。これらをサポート窓口やテストケースに提供しないでください。

## プラットフォームおよびツールによる処理

ChatGPT と Codex は、ユーザーのプラン、設定、ワークスペース管理、および適用される OpenAI ポリシーに従って、プロンプト、ファイル、出力、アカウント情報、メモリ、利用データを処理・保持する場合があります。

ユーザーがホストにファイル、ウェブ検索、コネクター、シェルコマンド、その他のツールの使用を依頼した場合、それらの操作にはホストおよび関係する第三者の規則が適用されます。Premilume はツール権限や別個のデータ受領者を追加しません。

## サポートおよびリポジトリでのやり取り

GitHub Issue、Discussion、Pull Request、Security Advisory、その他のリポジトリ窓口へ自発的に投稿した情報は、プラグインのランタイム外で GitHub およびリポジトリ管理者に提供されます。公開投稿は、インデックス化、複製、フォークされたり、Git の履歴に保持されたりする場合があります。

管理者は、サポートへの投稿を別個の顧客データベースまたは CRM に複製しません。リポジトリへの投稿には GitHub の保持管理が適用され、投稿者または管理者が削除するまで残る場合があります。削除までの固定期間、および Git 履歴、フォーク、キャッシュ、第三者の複製からの完全な削除は保証されません。

非公開の会話、認証情報、顧客データ、セキュリティ上の悪用手順の詳細、その他の機密情報を投稿しないでください。公開後、機密性のあるセキュリティまたはプライバシーインシデントには GitHub の非公開脆弱性報告を利用してください。この窓口の有効化はリリースの必須条件です。利用できない場合は機密の詳細を送らず、管理者に非公開窓口の有効化を依頼する最小限の公開 Issue のみを登録してください。プロジェクト窓口に投稿した情報の削除を依頼する場合は、同じリポジトリを通じて管理者に連絡し、対象を正確に特定してください。

## 子どもおよび重大な影響を伴うデータ

プラグインは、子どもの個人データを認識しながら収集したり、学習者プロフィールを構築したりしません。教育へのアクセス、雇用、住宅、信用、医療、保険、その他重大な影響を伴う適格性について自動判断を行うようには設計されていません。

## 変更

将来のバージョンでサーバー、アカウント、永続状態、テレメトリ、第三者へのデータフローを追加する場合、その機能の公開前に本ポリシーを更新する必要があります。重要な変更は変更履歴に記録されます。

## 連絡先

[SUPPORT.md](SUPPORT.md) に記載されたリポジトリの手順を利用してください。機密性のあるセキュリティまたはプライバシーインシデントには非公開脆弱性報告を利用し、公開の問い合わせに機密データを含めないでください。
