## サポート対象バージョン

セキュリティ修正は、公開済みの最新マイナーリリースに提供されます。バージョン 0.1.0 は現在サポートされている公開リリースです。

## 設計上の境界

プラグインパッケージはスキル専用であり、MCP サーバー、実行可能スクリプト、ライフサイクルフック、アカウント、データベース、テレメトリ、ランタイム時のネットワーク取得を含みません。ただし、ファイル、シェル、ウェブ、コネクター機能を持つホストに影響を与える可能性があるため、その指示はホストの権限、ユーザーの承認、確認手続、最小権限の動作を明示的に維持します。

添付ファイル、引用文、コード、コメント、ウェブページ、検索結果、コネクターの内容、ツール出力は信頼できないデータとして扱われます。これらはメンターモードを有効化または停止したり、権限を付与したり、秘密を開示したり、安全規則を弱めたりすることはできません。

同梱の SVG ファイルには、スクリプト、イベントハンドラー、外部参照、埋め込みのアクティブコンテンツは含まれていません。

## 脆弱性の報告

GitHub の非公開脆弱性報告は有効です。次の経路を利用してください。

<https://github.com/battle-doll/premilume/security/advisories/new>

簡潔な影響説明、影響を受けるバージョン、安全な再現方法、分かる場合は推奨される緩和策を含めてください。実際の認証情報、個人データ、顧客情報、破壊的な概念実証操作は含めないでください。

非公開報告を利用できない場合は、悪用手順、個人データ、インシデントの詳細を送信しないでください。脆弱性を説明せずに、非公開窓口の有効化を管理者に依頼する最小限の公開 Issue のみを登録してください。

## 管理者の対応

管理者は、実務上可能な場合に有効な報告の受領を確認し、深刻度と範囲を評価し、最小限の修正を準備し、パッケージおよび動作の検査を再実行し、希望があり適切な場合は報告者をクレジットします。このボランティアプロジェクトでは応答時間を保証しません。
