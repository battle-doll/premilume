## 問題を報告する前に

プラグインのバージョン、ホスト（ChatGPT または Codex）、動作環境、スキルを明示的に呼び出したか、会話に明確な `ON` 状態があったかを確認してください。可能であれば、機密性のない合成コンテンツを使い、新しい会話で問題を再現してください。

## 公開サポート

リポジトリの公開後は、次の GitHub Issues を利用してください。

<https://github.com/battle-doll/premilume/issues>

次の情報を含めてください。

- プラグインおよびホストのバージョン
- 言語および正確な合成プロンプト
- 期待する動作
- 実際に確認した動作
- 最小限の再現手順

認証情報、非公開の会話、顧客または勤務先のデータ、個人識別子、専有ファイル、機密情報を含むスクリーンショットを含めないでください。

## セキュリティ報告

データ漏えいや有害な操作につながり得る脆弱性またはプライバシーインシデントを公開 Issue として登録しないでください。[SECURITY.md](SECURITY.md) に従い、公開リポジトリで有効になった後は非公開脆弱性報告を利用してください。その非公開窓口が有効になるまで公開リリースは行えません。利用できない場合は機密の詳細を一切送らず、管理者に非公開窓口の有効化を依頼する最小限の Issue のみを登録してください。

## サポート範囲

管理者は、インストール、有効化、ルーティング、文書、再現可能なパッケージ不具合について支援する場合があります。緊急対応、専門的な医療・法律・金融助言、アカウント復旧、無関係なホストおよび第三者サービスの障害に関するサポートは提供できません。
