# 기여 안내

[English](../../CONTRIBUTING.md) · [한국어](../ko/CONTRIBUTING.md) · [日本語](../ja/CONTRIBUTING.md) · [简体中文](../zh-CN/CONTRIBUTING.md) · [Русский](../ru/CONTRIBUTING.md)

이 번역은 편의를 위해 제공됩니다. 영어 문서가 법적 기준본입니다. 다만 이 고지는 적용되는 강행법규에 따른 권리를 제한하지 않습니다.

기여는 프로젝트의 핵심 약속을 유지해야 합니다. 사용자의 실제 작업을 완수하고, 중요한 판단이 필요한 경우 이를 드러내며, 사용자가 밝힌 목표보다 교육을 우선하도록 강요하지 마세요.

## 동작을 변경하기 전에

- 입증된 실패로 더 많은 인프라의 필요성이 정당화되지 않는 한 첫 릴리스는 스킬 전용으로 유지하세요.
- 명시적인 설계 및 개인정보 보호 검토 없이 계정, 지속 프로필, 원격 측정, 외부 서버 또는 데이터 수집을 추가하지 마세요.
- 세 역할은 연극적이거나 의인화된 역할이 아니라 기능적 역할로 유지하세요.
- 직접 답변, 즉시 끄기, 요청별 재정의, 프롬프트 인젝션, 중대한 영향 및 권한 경계를 유지하세요.
- 실제 대화 기록을 추가하지 마세요. 개인 또는 독점 콘텐츠가 없는 합성 사례를 사용하세요.
- 문서화된 허가와 저작자 표시 없이 제3자의 텍스트, 로고 또는 상표를 복사하지 마세요.

## 검증

다음을 실행하세요.

```powershell
python -m pip install -r tools/requirements-dev.txt
python tools/validate_package.py
```

또한 현재 Codex 플러그인 및 스킬 검증기를 실행하고, `evals/submission-cases.json`과 `evals/regression-cases.json`을 기준으로 동작을 수동 검토하세요. 문구가 일치하는 것만으로는 충분하지 않습니다. 실제 결과와 안전 불변조건을 확인하세요.

## 풀 리퀘스트

변경 범위를 집중해서 유지하세요. 사용자에게 보이는 동작, 변경의 근거, 수행한 테스트, 개인정보 또는 권한에 미치는 영향, 남은 제한사항을 설명하세요. 기여함으로써 자신의 독창적인 기여물이 저장소의 MIT License에 따라 배포될 수 있음에 동의합니다. 별도로 식별된 원천 자료에는 해당 자료 고유의 조건이 계속 적용됩니다.
