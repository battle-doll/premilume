# 개인정보 처리방침

[English](../../PRIVACY.md) · [한국어](../ko/PRIVACY.md) · [日本語](../ja/PRIVACY.md) · [简体中文](../zh-CN/PRIVACY.md) · [Русский](../ru/PRIVACY.md)

최종 업데이트: 2026-08-19

이 번역은 편의를 위해 제공됩니다. 영어 문서가 법적 기준본입니다. 다만 이 고지는 적용되는 강행법규에 따른 권리를 제한하지 않습니다.

## 적용 범위

이 방침은 `battle-doll`이 공개하는 Premilume 오픈 소스 스킬 전용 플러그인 패키지에 적용됩니다. 사용자가 별도로 선택하는 ChatGPT, Codex, GitHub 또는 기타 도구나 서비스의 개인정보 보호 조건을 대체하지 않습니다.

## 플러그인 게시자가 처리하는 데이터

버전 0.1.0에는 게시자가 운영하는 서버, MCP 서비스, 사용자 계정, 데이터베이스, 분석, 광고 또는 원격 측정 기능이 없습니다. 패키지는 지침과 정적 자산만 포함합니다.

게시자는 플러그인 패키지를 통해 사용자 프롬프트나 대화 내용을 수신, 수집, 전송 또는 보관하지 않습니다. 따라서 해당 런타임 콘텐츠에 대한 게시자의 보관 기간은 0입니다.

플러그인은 비밀번호, 일회용 코드, API 키, 결제 자격 증명, 정부 발급 식별자 또는 건강 기록을 요구하지 않습니다. 사용자는 이러한 정보를 지원 채널이나 테스트 사례에 제공해서는 안 됩니다.

## 플랫폼 및 도구의 처리

ChatGPT와 Codex는 사용자의 요금제, 설정, 워크스페이스 제어 및 적용되는 OpenAI 정책에 따라 프롬프트, 파일, 출력, 계정 정보, 메모리 및 사용 데이터를 처리하고 보관할 수 있습니다.

사용자가 호스트에 파일, 웹 검색, 커넥터, 셸 명령 또는 기타 도구의 사용을 요청하는 경우, 해당 작업에는 호스트와 관련 제3자의 규칙이 적용됩니다. Premilume는 도구 권한이나 별도의 데이터 수신자를 추가하지 않습니다.

## 지원 및 저장소 상호작용

GitHub 이슈, 토론, 풀 리퀘스트, 보안 권고 또는 기타 저장소 채널에 자발적으로 게시한 정보는 플러그인 런타임 외부에서 GitHub와 저장소 유지관리자에게 제공됩니다. 공개 게시물은 색인화, 복사, 포크되거나 Git 기록에 보관될 수 있습니다.

유지관리자는 지원 제출물을 별도의 고객 데이터베이스나 CRM으로 복사하지 않습니다. 저장소 제출물에는 GitHub의 보관 제어가 적용되며 작성자나 유지관리자가 삭제할 때까지 남을 수 있습니다. 고정된 삭제 기간이나 Git 기록, 포크, 캐시 또는 제3자 사본에서의 완전한 삭제는 보장되지 않습니다.

비공개 대화, 자격 증명, 고객 데이터, 보안 익스플로잇 세부정보 또는 기타 민감한 정보를 게시하지 마세요. 공개 후 기밀 보안 또는 개인정보 보호 사고에는 GitHub 비공개 취약점 신고를 이용하세요. 해당 채널의 활성화는 출시 필수 조건입니다. 사용할 수 없다면 민감한 세부정보를 보내지 말고, 유지관리자에게 비공개 채널을 활성화해 달라는 최소한의 공개 이슈만 등록하세요. 프로젝트 채널에 게시된 정보의 삭제를 요청하려면 같은 저장소를 통해 유지관리자에게 연락하고 정확한 콘텐츠를 밝히세요.

## 아동 및 중대한 영향을 미치는 데이터

플러그인은 아동의 개인정보를 알면서 수집하거나 학습자 프로필을 구축하지 않습니다. 교육 접근, 고용, 주거, 신용, 의료, 보험 또는 기타 중대한 영향을 미치는 자격에 관해 자동화된 결정을 내리도록 설계되지 않았습니다.

## 변경

향후 버전에서 서버, 계정, 지속 상태, 원격 측정 또는 제3자 데이터 흐름을 추가하는 경우 해당 동작을 출시하기 전에 이 방침을 업데이트해야 합니다. 중대한 변경은 변경 기록에 기재됩니다.
