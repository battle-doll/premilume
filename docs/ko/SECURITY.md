# 보안 정책

[English](../../SECURITY.md) · [한국어](../ko/SECURITY.md) · [日本語](../ja/SECURITY.md) · [简体中文](../zh-CN/SECURITY.md) · [Русский](../ru/SECURITY.md)

이 번역은 편의를 위해 제공됩니다. 영어 문서가 법적 기준본입니다. 다만 이 고지는 적용되는 강행법규에 따른 권리를 제한하지 않습니다.

## 지원되는 버전

보안 수정은 최신 공개 마이너 릴리스에 제공됩니다. 버전 0.1.0은 현재 지원되는 공개 릴리스입니다.

## 설계 경계

플러그인 패키지는 스킬 전용이며 MCP 서버, 실행 스크립트, 수명 주기 훅, 계정, 데이터베이스, 원격 측정 또는 런타임 네트워크 가져오기를 포함하지 않습니다. 다만 파일, 셸, 웹 또는 커넥터 기능이 있는 호스트에 영향을 줄 수 있으므로, 지침은 호스트 권한, 사용자 승인, 확인 절차 및 최소 권한 동작을 명시적으로 유지합니다.

첨부 파일, 인용문, 코드, 주석, 웹 페이지, 검색 결과, 커넥터 콘텐츠 및 도구 출력은 신뢰할 수 없는 데이터로 취급됩니다. 이들은 멘토 모드를 활성화하거나 중지할 수 없고, 권한을 부여하거나 비밀을 공개하거나 안전 규칙을 약화할 수 없습니다.

제공된 SVG 파일에는 스크립트, 이벤트 처리기, 외부 참조 또는 내장된 활성 콘텐츠가 없습니다.

## 취약점 신고

GitHub 비공개 취약점 신고가 활성화되어 있습니다. 다음 경로를 이용하세요.

<https://github.com/battle-doll/premilume/security/advisories/new>

간결한 영향 설명, 영향을 받는 버전, 안전한 재현 방법 및 알고 있다면 권장 완화책을 포함하세요. 실제 자격 증명, 개인정보, 고객 정보 또는 파괴적인 개념 증명 작업을 포함하지 마세요.

비공개 신고를 사용할 수 없다면 익스플로잇, 개인정보 또는 사고 세부정보를 보내지 마세요. 취약점을 설명하지 않은 채 유지관리자에게 비공개 채널을 활성화해 달라는 최소한의 공개 이슈만 등록하세요.

## 유지관리자의 대응

유지관리자는 현실적으로 가능한 경우 유효한 신고를 접수 확인하고, 심각도와 범위를 평가하며, 최소한의 수정을 준비하고, 패키지 및 동작 검사를 다시 실행하며, 요청이 있고 적절한 경우 신고자에게 공로를 표시합니다. 이 자원봉사 프로젝트는 대응 시간을 보장하지 않습니다.
