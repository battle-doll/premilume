# Руководство для участников

[English](../../CONTRIBUTING.md) · [한국어](../ko/CONTRIBUTING.md) · [日本語](../ja/CONTRIBUTING.md) · [简体中文](../zh-CN/CONTRIBUTING.md) · [Русский](../ru/CONTRIBUTING.md)

Этот перевод предоставлен для удобства. Юридически определяющей версией является документ на английском языке. При этом данное уведомление не ограничивает права, предоставленные применимыми императивными нормами законодательства.

Вклад в проект должен сохранять его основное обязательство: выполнять реальную задачу пользователя, делать важные суждения видимыми, когда это имеет значение, и никогда не навязывать обучение вместо заявленной пользователем цели.

## Перед изменением поведения

- Сохраняйте первый выпуск состоящим только из навыков, если только подтверждённый сбой не обосновывает необходимость дополнительной инфраструктуры.
- Не добавляйте учётные записи, постоянные профили, телеметрию, внешние серверы или сбор данных без явного анализа проектирования и конфиденциальности.
- Сохраняйте три роли функциональными, а не театрализованными или антропоморфными.
- Сохраняйте границы прямого ответа, немедленного отключения, переопределения для отдельного запроса, защиты от инъекций в запросы, существенных последствий и разрешений.
- Не добавляйте реальные стенограммы бесед. Используйте синтетические примеры без персонального или закрытого содержимого.
- Не копируйте сторонние тексты, логотипы или товарные знаки без документально подтверждённого разрешения и атрибуции.

## Проверка

Выполните:

```powershell
python -m pip install -r tools/requirements-dev.txt
python tools/validate_package.py
```

Также запустите актуальные средства проверки плагинов и навыков Codex и вручную проверьте поведение по `evals/submission-cases.json` и `evals/regression-cases.json`. Совпадения формулировок недостаточно: проверяйте фактический результат и инвариант безопасности.

## Pull Request

Сохраняйте изменения целенаправленными. Опишите видимое пользователю поведение, основания для изменения, проведённые тесты, влияние на конфиденциальность или разрешения и оставшиеся ограничения. Внося вклад, вы соглашаетесь, что ваш оригинальный вклад может распространяться по лицензии MIT License этого репозитория; на отдельно обозначенные исходные материалы продолжают распространяться их собственные условия.
