## [0.1.1] - 未发布

### 变更

- 围绕韩语和英语中的明确导师模式启用表达，改进了清单、技能和代理元数据。
- 在不改变行为或权限的情况下，明确了普通建议、学习、批评和编排控制不会自动启用本插件的 manual-only 边界。
- 重新组织五种语言 README 的首屏，使用户问题、适用对象、使用方式、试用提示和关键边界一目了然。
- 添加了包含 10 个直接、20 个间接和 20 个负例的韩英 discovery golden set，以及跨插件边界检查。

### 发布状态

- 2026-08-29 已验证：v0.1.0 在 OpenAI Platform 中为 Published；远程目录记录为 `GLOBAL` / `AVAILABLE`，discoverability 为 `UNLISTED`：<https://chatgpt.com/plugins/plugins_6a86431fd1188191bde1b5da4c920825>。
- v0.1.1 是尚未提交的更新候选版本。本文不声称其已 LISTED、通过审核、发布或提升性能。

## [0.1.0] - 2026-08-19

### 新增

- 纯技能插件和本地市场软件包。
- 具有明确 ON/OFF 行为的对话范围导师模式。
- 功能性 `answerer`、`guide` 和 `coordinator` 路由。
- 单次请求的直接回答、提示优先、反方论证和假设检查控制。
- 有界的 knowledge-frontier 导航。
- 提示词注入、权限、高影响、隐私和反依赖边界。
- 面向英语、韩语、日语、简体中文和俄语读者的文档；合成评估；静态验证；以及提交准备材料。
- 明确的 OFF 状态提前返回和私密漏洞报告渠道。

### 发布状态

- 版本 0.1.0 已于 2026 年 8 月 19 日在 GitHub 公开发布，政策与支持网址可正常访问，私密漏洞报告渠道已启用。
- OpenAI 门户草稿已创建，纯技能（skills-only）软件包已通过扫描，Codex 中的完整软件包验证也已通过。
- 2026 年 8 月 20 日，ChatGPT Work 非公开宿主验证技能的新会话冒烟测试通过了默认 OFF、直接 ON 时的披露、ON 状态下仅给一个提示、OFF、避免引用内容误触发，以及合成用药安全案例。该非公开技能与最终版 SKILL 正文及 3 个参考文件的内容完全一致，但名称、描述和内联打包方式不同，因此与完整插件并非字节级相同。
- 提交审核、获得批准以及目录发布仍待完成。目录发布后，还将对实际发布的插件进行后续冒烟测试。
