贡献内容应维护项目的核心约定：完成用户的实际任务；在重要判断确有必要时保持判断可见；绝不强制将教学置于用户明确表达的目标之上。

## 更改行为之前

- 除非经证实的故障足以证明需要更多基础设施，否则首个版本应保持为纯技能形式。
- 未经明确的设计和隐私审查，不得添加账户、持久化档案、遥测、外部服务器或数据收集。
- 三个角色应保持功能性，而非戏剧化或拟人化。
- 保持直接回答、立即关闭、按请求覆盖、提示词注入、高影响和权限边界。
- 请勿添加真实对话记录。请使用不含个人或专有内容的合成用例。
- 未经有据可查的许可和署名，请勿复制第三方文本、标识或商标。

## 验证

运行：

```powershell
python -m pip install -r tools/requirements-dev.txt
python tools/validate_package.py
```

还应运行当前 Codex 插件和技能验证器，并根据 `evals/submission-cases.json` 和 `evals/regression-cases.json` 手动审查行为。仅仅措辞匹配是不够的；请检查实际结果和安全不变量。

## Pull Request

请保持变更重点明确。说明用户可见的行为、变更依据、所执行的测试、对隐私或权限的影响，以及任何剩余限制。提交贡献即表示您同意，您的原创贡献可依据本代码库的 MIT License 进行分发；另行标明的源材料仍适用其自身条款。
