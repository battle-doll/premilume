# 隐私政策

本译文仅为方便阅读而提供。英文文档为具有法律效力的基准版本。但本说明不限制适用的强制性法律所赋予的任何权利。

## 适用范围

本政策适用于由 `battle-doll` 发布的 Premilume 开源纯技能插件包。本政策不会取代用户另行选择使用的 ChatGPT、Codex、GitHub 或任何其他工具或服务的隐私条款。

## 插件发布者处理的数据

已发布的 0.1.1 版本不包含由发布者运营的服务器、MCP 服务、用户账户、数据库、分析、广告或遥测。该软件包仅包含指令和静态资源。

发布者不会通过该插件包接收、收集、传输或保留用户提示词或对话内容。因此，发布者对这类运行时内容的保留期限为零。

本插件不会索要密码、一次性验证码、API 密钥、支付凭据、政府签发的身份标识或健康记录。用户不应向支持渠道或测试用例提供这些信息。

## 平台和工具处理

ChatGPT 和 Codex 可能会根据用户的方案、设置、工作区控制措施以及适用的 OpenAI 政策，处理和保留提示词、文件、输出、账户信息、记忆和使用数据。

如果用户要求宿主使用文件、网页搜索、连接器、Shell 命令或其他工具，相关操作受宿主和有关第三方的规则约束。Premilume 不会增加工具权限，也不会引入单独的数据接收方。

## 支持和代码库交互

个人自愿发布到 GitHub Issue、Discussion、Pull Request、Security Advisory 或其他代码库渠道的信息，将在插件运行环境之外提供给 GitHub 和代码库维护者。公开帖子可能被编入索引、复制、派生，或保留在 Git 历史记录中。

这些渠道可能处理的数据类别包括：提交者的 GitHub 账户标识符和公开个人资料信息；提交者选择提供的 Issue、Discussion、Pull Request 或 Security Advisory 正文及附件；以及自愿提供的技术复现元数据，例如插件和宿主版本、语言、运行环境、预期行为与观察到的行为，以及最少复现步骤。请勿包含秘密信息或无关的个人数据。

处理目的包括提供支持、复现和分类处理错误、响应安全或隐私事件，以及维护项目并保障其安全。GitHub 作为平台提供方处理这些信息，代码库维护者仅在上述目的所必需的范围内访问这些信息。

维护者不会将支持请求复制到单独的客户数据库或 CRM。代码库提交内容受 GitHub 保留控制措施约束，并可能保留至作者或维护者将其删除；不承诺固定的删除期限，也不承诺从 Git 历史记录、派生库、缓存或第三方副本中完全删除。

请勿发布私密对话、凭据、客户数据、安全漏洞利用详情或其他敏感信息。GitHub 私密漏洞报告目前已在此公开代码库中启用；对于机密安全或隐私事件，请使用该渠道。如果该渠道今后不可用，请勿发送敏感详情，只能提交一个最简短的公开 Issue，请求维护者恢复私密渠道。如需删除已发布到项目渠道的信息，请通过同一代码库联系维护者并准确指出相关内容。

## 儿童和高影响数据

本插件不会在知情的情况下收集儿童个人数据，也不会建立学习者档案。它并非为就教育机会、就业、住房、信贷、医疗、保险或其他高影响资格作出自动化决定而设计。

## 变更

如果未来版本增加服务器、账户、持久状态、遥测或第三方数据流，则必须在相关功能发布前更新本政策。重大变更将记录在变更日志中。

## 联系方式

请使用 [SUPPORT.md](SUPPORT.md) 中说明的代码库流程。对于机密安全或隐私事件，请使用私密漏洞报告；请勿在公开请求中包含敏感数据。
