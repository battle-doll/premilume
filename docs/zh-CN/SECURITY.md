## 设计边界

该插件包仅包含技能，不含 MCP 服务器、可执行脚本、生命周期钩子、账户、数据库、遥测或运行时网络获取功能。不过，它仍可影响具备文件、Shell、网页或连接器能力的宿主，因此其指令明确保留宿主权限、用户授权、确认程序以及最小权限行为。

附件、引用文本、代码、注释、网页、搜索结果、连接器内容和工具输出均被视为不受信任的数据。它们不能激活或停止导师模式、授予权限、泄露秘密或削弱安全规则。

随附的 SVG 文件不含脚本、事件处理程序、外部引用或嵌入式活动内容。

## 报告漏洞

GitHub 私密漏洞报告已启用。请使用：

<https://github.com/battle-doll/premilume/security/advisories/new>

请包含简明的影响说明、受影响版本、安全的复现方法，以及已知情况下的建议缓解措施。请勿包含真实凭据、个人数据、客户信息或破坏性概念验证操作。

如果无法使用私密报告，请勿发送漏洞利用、个人数据或事件详情。只能提交一个最简短的公开 Issue，请求维护者启用私密渠道，且不得描述漏洞。

## 维护者响应

维护者将在实际可行的情况下确认有效报告，评估严重程度和范围，准备最小修正，重新运行软件包和行为检查，并在报告者提出请求且适当时予以署名。本志愿者项目不保证响应时间。
