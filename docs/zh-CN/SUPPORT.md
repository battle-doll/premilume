## 报告问题之前

请确认插件版本、宿主（ChatGPT 或 Codex）、运行环境、是否明确调用了该技能，以及对话中是否存在明确的 `ON` 状态。条件允许时，请在新对话中使用不敏感的合成内容复现问题。

## 公开支持

代码库发布后，请使用以下 GitHub Issues：

<https://github.com/battle-doll/premilume/issues>

请包括：

- 插件和宿主版本；
- 语言和准确的合成提示词；
- 预期行为；
- 观察到的行为；
- 最少复现步骤。

请勿包含凭据、私密对话、客户或雇主数据、个人标识符、专有文件，或含有敏感信息的屏幕截图。

## 安全报告

对于可能暴露数据或促成有害操作的漏洞或隐私事件，请勿提交公开 Issue。请遵循 [SECURITY.md](SECURITY.md)，并在公共代码库启用该功能后使用私密漏洞报告。在启用该私密渠道之前，不得公开发布。如果该渠道不可用，请勿发送任何敏感详情，只能提交一个最简短的 Issue，请求维护者启用私密渠道。

## 支持范围

维护者可以协助处理安装、激活、路由、文档和可复现的软件包缺陷。他们无法提供应急响应、专业医疗／法律／金融建议、账户恢复，也无法支持与本项目无关的宿主及第三方服务中断。
